# Todo List

A browser-based battleship game built with vanilla JavaScript, tested with Jest, and bundled with Webpack. Made as part of The Odin Project curriculum.

Project from [The Odin Project](https://www.theodinproject.com/lessons/node-path-javascript-battlehsip) — JavaScript course.

## Live Demo

[View Demo](https://ttnluong.github.io/odin-battleship/)

## Features

- Play against a computer opponent
- Randomly placed ships for the player (placeShipsRandom)
- Click enemy squares to attack; boards re-render after every move
- Computer makes smarter moves and never fires at the same square twice
- Hits, misses, and sunk ships are shown on the board
- Game ends when one side's ships are all sunk
- "New Game" button to reset the boards

## Tech Stack

- HTML5 / CSS3
- Vanilla JavaScript (ES modules)
- Webpack
- Jest + Babel

## Concepts Practiced

- Logic and DOM are separate
- Test-driven development
- Controller uses public methods only
